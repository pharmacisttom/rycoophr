# ขอบเขต rycoopHR 0.2

ฐานระบบ: Tomvis V2 alpha จาก https://github.com/pharmacisttom/tomvis2.0.git
บทความ: “ระบบบริหารบุคคลสำหรับสหกรณ์ออมทรัพย์ / Personnel Management System for Savings Cooperative”, อลงกต กองมณี และคณะ, เอกสาร R67026[1].pdf ที่ผู้ใช้ให้
เทคโนโลยีใช้ Node/SQLite ของต้นแบบ แทน C#/SQL Server ของงานวิจัย

สูตรเงินเดือนเพิ่มในบทความ N = S + S×X/100; รุ่นนี้ HR กำหนดอัตราเงินเดือนที่รับรองแล้ว
สูตรหักโบนัสในบทความมีความคลุมเครือ จึงใช้ยอดหักที่ฝ่ายการเงินยืนยัน ไม่มีการตั้งภาษีอัตโนมัติ
เก็บยอดเงินเป็นจำนวนเต็มหน่วยสตางค์ เพื่อหลีกเลี่ยงผลคลาดเคลื่อนจากเลขทศนิยม

## สิ่งที่ต้องกำหนดร่วมกับสหกรณ์

- สิทธิ์และเพดานค่ารักษาพยาบาล/ค่าเล่าเรียนบุตร OT และจำนวนวันลา ไม่ควรนำค่าตัวอย่างงานวิจัยไปเป็นระเบียบจริง
- Schema/API ของระบบเงินฝากและระบบการเงินยังไม่มีในคำขอ จึงยังไม่ส่งรายการการเงินไปยังระบบจริง
- ระบบประเมินกรรมการใช้คะแนน 0–100 ต่อชิ้นงาน ไม่มีการคำนวณค่าตอบแทนหรือการจัดอันดับอัตโนมัติ
- ประมวลผลขาดงานสำหรับทะเบียนที่ HR ยืนยันว่าปฏิบัติงานในวันนั้น ตรวจวันเริ่มงานและสถานะการจ้างก่อนเลือกวันที่ย้อนหลัง
- GPS เป็นหลักฐานประกอบจากเบราว์เซอร์ ไม่รับรองว่าอุปกรณ์ไม่ปลอมตำแหน่ง
