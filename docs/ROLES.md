# บทบาทและขอบเขตข้อมูล

| บทบาทระบบ   | หน้าที่                                                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------- |
| admin       | บัญชี pharmacisttom@gmail.com; ตั้งค่าองค์กร GPS บัญชี HR และกรรมการ ต้องใช้ 2FA                                          |
| it_admin    | งานนักคอมพิวเตอร์: ดูแลบัญชีพื้นฐาน/ตรวจ audit ไม่มีสิทธิ์เงินเดือน/สวัสดิการ/ประเมินกรรมการ และสร้างบัญชีสิทธิ์สูงไม่ได้ |
| hr_officer  | ดูทะเบียน จัดทำเงินเดือน/สวัสดิการ นำเข้าเวลา และประมวลผลขาดงาน                                                           |
| manager     | ดูข้อมูล HR และอนุมัติรายการที่ตนไม่ได้จัดทำ                                                                              |
| staff       | เช็กอินมือถือ ดูเวลาตนเอง ยื่นและดูใบลาตนเอง ไม่มีสิทธิ์ดูเงินเดือนผู้อื่น                                                |
| chair       | ดูภาพรวมกรรมการ มอบหมายงานและประเมินงานของคนอื่น ไม่มีสิทธิ์เงินเดือน/สุขภาพเจ้าหน้าที่                                   |
| director    | ดูหน้าข้อมูลตนเองและงานตนเอง บันทึกผลงานและส่งประเมิน                                                                     |
| viewer      | ดู feedback ที่มีอยู่ในฐานต้นแบบ                                                                                          |
| super_admin | บทบาทเดิมของ Tomvis ที่สงวนไว้ ไม่มีบัญชีที่ provision ในรุ่นนี้                                                          |

ตำแหน่งจริง เช่น รองประธาน เลขานุการคณะเงินกู้ หรือเจ้าหน้าที่บัญชี เก็บแยกจากบทบาทสิทธิ์
กรรมการหนึ่งคนมีคณะย่อยได้หลายคณะ ข้อมูลเว็บถูกเก็บเป็นโปรไฟล์โดยไม่เปิดบัญชีอัตโนมัติ
ผู้จัดทำไม่อนุมัติรายการตนเอง ผู้ประเมินไม่ประเมินงานตนเอง ตรวจสิทธิ์และ tenant ที่ backend ทุกครั้ง

การสร้างบัญชีเจ้าหน้าที่ให้เลือกทะเบียนที่ผูกตรงกันก่อนใช้เช็กอินและใบลา
อีเมลแอดมินเป็นชื่อบัญชีในระบบนี้ Google Authenticator ใช้ TOTP; ยังไม่มี Google OAuth/การเข้าสู่ระบบด้วย Gmail
